# Georgia Early Vote 2026 dashboard — data spec

Same page design and JSON formats as the other kits (Ohio, Iowa, Texas, Michigan, North Carolina, Kansas); only build.py's
STATE block and ALIAS differ. Queries are generated by `q.py` (in this folder) so the SQL is never retyped:
`python3 q.py GA KIND [YEAR] [ASOF]`. Run each with `mcp__Google_Cloud_BigQuery__execute_sql_readonly`, keep the saved
result file (every query has a `pad` column so the harness saves it to a file), copy it to `bq/`, convert with the helper.

| File | Query (q.py kind) | Convert |
|---|---|---|
| daily.json | `S 2026`, `S 2024`, `S 2022` and `T` (totals, all years) | paste T's three rows into `make_daily.py` TOT, then `make_daily.py data/daily.json bq/S_2026.json bq/S_2024.json bq/S_2022.json` |
| county_daily_YYYY.json | `C2 YYYY` (compact: one row per county, days packed as JSON, so one query per year fits under the 3,000-row cap) | `compact.py county data/county_daily_YYYY.json bq/C_YYYY.json` |
| precinct_2026.json | `P2` (compact, one row per county) | `compact.py precinct data/precinct_2026.json bq/P_2026.json` |
| heat_2026.json / heat_2022.json | `H 2026 ASOF`, `H 2022 ASOF` | `heat_merge.py data/heat_YYYY.json bq/H_YYYY.json` |
| proj.json | `M 2022 ASOF`, `M 2024 ASOF`, `M 2026 ASOF` (PROJECTION.md) | `make_proj.py data/proj.json GA ASOF bq/M_2022.json bq/M_2024.json bq/M_2026.json` |
| counties.json | static (geo/make_geo.py from Census cb_2023_us_county_20m) | — |
| precincts/*.json | static, built once: `B2` → `compact.py blocks geo/precinct_blocks.json bq/B.json`, `blockpts.py`, `match_precincts.py` | — |

Run `compact.py` from the kit folder (it reads ALIAS from `merge_county.py` there). The `C`, `P` and `B` kinds (chunked by
county) also still work with `merge_county.py` / `merge_precinct.py` if the compact form ever exceeds a result size limit.

County of an ABEV row: `REGEXP_REPLACE(UPPER(a.Jurisname), ' COUNTY$', '')`, NULL → `UNKNOWN`. Voter-file county:
`UPPER(CountyName)`. Aliases (to the Census NAME.upper() used by counties.json): `DE KALB`→`DEKALB` (voter file, and part of the feed), `BENHILL`→`BEN HILL`, `JEFFDAVIS`→`JEFF DAVIS` (2024 feed).
Party: modeled party (Georgia has no party registration; `PartyRollUp` is `Modeled Republican` / `Modeled Democrat` / `Modeled Independent/Unaffiliated` for every voter), from the voter file of each year (voters / voterfile_2024 / voterfile_2022), mapped to R / D / O by
`CASE WHEN PartyRollUp IN ('Republican','Modeled Republican') THEN 'R' WHEN PartyRollUp IN ('Democrat','Modeled Democrat') THEN 'D' ELSE 'O' END`.
Counts: requested = RequestDate not NULL and Rejected = 0; returned = ReturnDate not NULL and Rejected = 0; in-person early =
EarlyVoted not NULL; d = days before Election Day (2026-11-03, 2024-11-05, 2022-11-08). The GitHub Action
(`build/ev_refresh.py`) runs the same SQL with the Python client.
